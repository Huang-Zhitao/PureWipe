# PureWipe v1.3.0

LEATHY™ Studio 出品 Windows 纯净强力系统清理工具

## 项目特点

1. 极致轻量化

   * 编译成品仅 64KB+，运行内存占用不足 1MB
   * 无后台驻留、无广告、无捆绑、不读写隐私
2. 全自动管理员提权
未获取管理员权限时自动弹窗申请权限，无需手动右键运行
3. 四层深度清理+系统修复

   * 阶段1：系统/用户临时目录安全清理（移除全盘\*.tmp高危扫描逻辑，避免误删业务文件）
   * 阶段2：缩略图缓存、Windows更新缓存、Edge/Chrome浏览器缓存、商店缓存
   * 阶段3：WinSxS组件清理、休眠文件、Windows.old、回收站、大容量冗余文件（移除自动清理下载文件夹安装包逻辑）
   * 阶段4：DISM系统镜像修复、SFC系统文件校验、磁盘修复（移除批量全量DLL注册卡死代码）
4. 分级风险确认机制

   * 高危删除：Windows.old、全盘回收站、组件重置等不可逆操作弹窗确认，可一键跳过
   * 次级网络风险：IP栈/Winsock重置独立弹窗，重点警示企业静态IP/域主机断网风险，按需跳过
5. 新增控制台实时进度条
全流程可视化进度展示，清晰查看当前步骤与完成百分比，区分正常运行与程序卡死
6. 兼容全版本 Windows
Win10 全版本 / Win11 正式版 / Win11 Canary 预览版(26200+)
ResetBase 设为可选高危项，新版系统报错不阻断流程

## 清理收益

* 休眠关闭：释放与内存同等大小空间
* Windows.old：10\~35GB
* WinSxS + 更新缓存：5\~15GB
* 浏览器/缩略图/临时日志：2\~8GB

## v1.2.2 旧版已知严重缺陷（v1.3.0 全部修复）

\*无进度可视化，无法判断程序运行状态，卡顿难以识别。\*
